# The bags edit

The owner selected these USD prices: Sculptural Tote $200; Crescent $125; Petal $175; Vanity Case $190; Fold $140; Arc Satchel $150; Circle $165; Portrait $160. Colors of one style share a price. Display conversion uses the existing USD/KES/GBP reference rates and cart arithmetic.

The homepage, shop banner, `/bags`, bag category, collection and product recommendations link this edit. Product galleries show only supplied views for the selected color; switching color resets the view. The Portrait duo is displayed with SVG viewBox panels referencing the untouched original. Gallery dimensions and single-size selections do not imply verified physical measurements.

`public/assets/bags-editorial.png` is an AI campaign composition generated from the supplied burgundy/indigo portrait-bag duo: both oval-panel designs on warm limestone with natural sun, preserving the supplied silhouettes and hardware, with no typography. It is labelled as a campaign composition. Product assets remain the supplied originals.
